Entry for make.fun's "One Line, One Chill" bounty ($5): one funny chill line — in this competition's own terms, a single sentence of horror under 200 characters, written to frighten a reader in one breath.

## What it does

`main.ts` (Node 22, standard library only, no network, deterministic) writes one line of horror to `/output/entry.txt`:

> My daughter's baby monitor has started narrating my movements in my own voice, three seconds before I move.

The scare is earned, not announced: a familiar household object, a voice that should be mine, and a three-second head start that says whatever is speaking knows what I will do before I do.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
